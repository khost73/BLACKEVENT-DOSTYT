# BLACKEVENT-DOSTYT
✨ Инструмент для активного и дружелюбного чата на YouTube Live  Этот проект помогает создавать оживлённую и позитивную атмосферу в чате YouTube-стримов! 

## 🚀 Что это?

**BLACKEVENT-DOSTYT** — скрипт для автоматической отправки сообщений в YouTube чат:  
- Случайные фразы из списка или свой текст  
- Настройка количества сообщений и задержки  
- Эмуляция нажатий клавиш с помощью `keyboard`


## ⚡ Как использовать

1. Войдите во все аккаунты в браузере.  
2. Откройте стрим и разверните чат на полный экран.  
3. Поочерёдно переключитесь на каждый аккаунт и откройте чат стрима в полном окне.  
4. В каждом чате кликните в поле ввода сообщения.  
5. Запустите программу и выберите 3 настройки.  
6. После третьего выбора быстро переключитесь в браузер с чатами — начнётся автоматический спам.
